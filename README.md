# Nythxion Watermarker

**Nythxion Watermarker** is a watermarking application developed by **Nythxion Studios**.

It can apply visible and holographic watermarks to images, generate unique watermark IDs, verify existing artworks, save watermark configurations, and integrate with Figma.

## Features

* Visible image watermarking
* Holographic watermark embedding
* Unique watermark IDs
* Watermark verification
* Artwork Archive
* AI Instruction support
* Alpha fingerprinting
* Persistent local archive
* Saves system for watermark configurations
* Redesigned user interface
* Figma application integration
* Windows desktop application
* Fast and lightweight

## Saves

The **Saves** system allows watermark configurations to be saved and reused.

Saved configurations can store watermark settings so they can be quickly applied without manually configuring the Watermarker each time.

This makes it possible to maintain different configurations for different types of artwork.

## Artwork Archive

The Artwork Archive stores information about watermarked artwork locally.

Each archive entry contains:

* Artwork name
* Watermark ID
* Creation date
* Verification status

Artwork names can be renamed or removed from the archive at any time.

The archive is stored locally on your computer and is not uploaded to Nythxion Studios.

## Watermark Verification

Nythxion Watermarker uses the embedded watermark ID to verify artwork.

If the watermark ID exists in the local Artwork Archive, the artwork can be identified using its archived information.

> **Important:** Applying a new watermark to an already-watermarked image may invalidate or overwrite its existing watermark.

## AI Instruction

The AI Instruction adds an additional layer of protection intended to discourage AI systems from removing or altering the watermark.

> **Important:** AI Instruction does not guarantee complete protection. Advanced tools or systems may ignore the instruction and still remove or modify the watermark.

## Figma Integration

Nythxion Watermarker is also available as a **Figma application**.

The Figma integration allows artwork to be exported and processed using Nythxion Watermarker.

The Figma application can synchronize watermark configuration with the desktop application through a local connection.

## User Interface

Version 1.1.0 introduces a redesigned Nythxion Watermarker interface.

The new UI provides a cleaner and more organized experience for configuring, saving, verifying, and managing watermarked artwork.

## Privacy

Nythxion Watermarker is designed to operate locally on your computer.

Your Artwork Archive and saved configurations are stored locally and are not automatically uploaded to Nythxion Studios.

## System Requirements

### Recommended

* Windows 10 or later
* 64-bit processor
* 4 GB RAM or more
* Approximately 500 MB of available storage

## Installation

No traditional installer is required.

1. Extract the ZIP archive.
2. Open the extracted **Nythxion-Watermarker** folder.
3. Launch **Nythxion Watermarker.exe**.

Do not move, delete, or modify files from the application folder after extraction.

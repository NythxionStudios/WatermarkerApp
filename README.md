# Nythxion Watermarker

**Nythxion Watermarker** is a watermarking app developed by **Nythxion Studios**.

It can apply visible and holographic watermarks to images, generate unique watermark IDs, and verify existing artworks.

## Features

- Visible image watermarking
- Holographic watermark embedding
- Unique watermark IDs
- Watermark verification
- Artwork Archive
- AI Instruction support
- Persistent local archive
- Windows desktop application
- Fast and lightweight

## Artwork Archive

The Artwork Archive stores information about watermarked artwork locally.

Each archive entry contains:

- Artwork name
- Watermark ID
- Creation date
- Verification status

Artwork names can be renamed or removed from the archive at any time.

The archive is stored locally on your computer and is not uploaded to Nythxion Studios.

## Watermark Verification

Nythxion Watermarker uses the embedded watermark ID to verify artwork.

If the watermark ID exists in the local Artwork Archive, the artwork can be identified using its archived information.

> **Important:** Applying a new watermark to an already-watermarked image may invalidate or overwrite its existing watermark.

## AI Instruction

The AI instruction adds an extra layer of security to protect against AI removing the watermarks
> **Important:** We can't guarantee that your image is 100% protected from AI, advanced tools can ignore the instruction and still remove the watermark.

## Privacy

Nythxion Watermarker is designed to operate locally on your computer.

Your Artwork Archive is stored locally and is not automatically uploaded to Nythxion Studios.

## System Requirements

### Recommended

- Windows 10 or later
- 64-bit processor
- 4 GB RAM or more
- Approximately 500 MB of available storage

## Installation

No traditional installer is required.

1. Extract the ZIP archive.
2. Open the extracted **Nythxion-Watermarker** folder.
3. Launch **Nythxion Watermarker.exe**.

Do not move, delete or modify files from the application folder after extraction.
